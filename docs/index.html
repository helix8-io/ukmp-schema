This is a demonstration implementation of the UK Materials Passport Schema v0.1-draft checks (structure, recycled-content arithmetic, mass-balance reconciliation, conformance level). The canonical validator is tools/validate.py in the repository. Cryptographic proof verification (Level 3) is indicated, not performed, in this browser demo.
