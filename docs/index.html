Everything runs locally in your browser; nothing is uploaded. The checks mirror tools/validate.py.

This is a demonstration implementation of the UK Materials Passport Schema v0.2-draft checks: JSON Schema 2020-12 validation against schema/material_passport.schema.json, recycled-content arithmetic (including every recycledContentDetail entry), mass-balance reconciliation, conformance-level detection, and the v0.2 identity, lifecycle and JSON Pointer warnings. Every v0.1 passport remains valid. The canonical validator is tools/validate.py. Cryptographic proof verification (Level 3) is indicated, not performed — in this demo and in validate.py. All example values are illustrative.
